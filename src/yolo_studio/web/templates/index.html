03 Preview performance
What do these settings mean?
Inference size
Pixels used by the model. Larger can detect finer details, but is slower.
Confidence
Minimum object/person score. Lower finds more candidates, including more false positives.
Preview width
Maximum transmitted video width. Smaller saves bandwidth; the camera’s viewing angle stays the same.
Output FPS cap
A maximum rate, not a guarantee. Lower caps reduce network and processing load.
JPEG quality
Higher gives sharper frames with larger files. Lower quality uses less bandwidth.
Faster preview
Sets nano, 320 inference pixels, 640 preview width, 60% JPEG quality and a 20 FPS cap. Your feature choices and runtime stay as selected. Apply changes to use it.
Compare raw feed
Unchecks all CV features. Apply changes to view the camera without inference and diagnose network versus processing delays.
